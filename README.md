# My Capstone Project

A capstone project for the AI-assisted development track.

## About

This repository documents my capstone work using AI-assisted development with Cursor. The goal is to build software iteratively with clear git history, conventional commits, and AI-guided code review throughout the track.

## Stack

- Node.js (LTS)
- npm
- Cursor (IDE)

## Prerequisites

- [Node.js LTS](https://nodejs.org/) (v22 or later recommended)
- [Git](https://git-scm.com/)
- [Cursor](https://cursor.com/)

## Getting started

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd my-capstone-project
npm install
```

## Project structure

```text
.
├── CLAUDE.md      # AI assistant conventions for this repo
├── LICENSE        # MIT license
├── README.md      # Project overview
├── package.json   # Node.js manifest
└── .gitignore     # Ignored files and folders
```

## Development

- Follow [Conventional Commits](https://www.conventionalcommits.org/) for all commit messages.
- Read `CLAUDE.md` before asking Cursor Agent for architectural changes.
- Keep commits small and focused on one logical change.
